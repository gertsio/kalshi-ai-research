# Work Docs Agent Notes

Follow `../agents/issue-tracker.md`. It is the source of truth for using the local issue tracker under `docs/work/`.

This directory contains durable specs, ticket manifests, ticket files, and workstream-scoped agent notes. Existing repos may keep `prd` and `issue` filenames/keys as compatibility storage names.

If the target workstream, spec, or ticket is ambiguous, ask one short question.
